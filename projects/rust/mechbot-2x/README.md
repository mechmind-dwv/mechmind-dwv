# 🦀 MechBot-2X

El proyecto estrella de la serie Mech. Un robot diseñado para la innovación y la eficiencia utilizando Rust.

## 🚧 Estado del Proyecto: En Progreso

Este módulo contiene la lógica específica de control y comportamiento para el hardware del MechBot-2X.

## 🚀 Compilación

```bash
cargo build -p mechbot-2x
```

## 🛠️ Tecnologías

- **Rust**: Lógica de control de bajo nivel.
- **Tokio**: Gestión de tareas asíncronas.
- **Serde**: Serialización de datos de sensores.
