# MechMind Cyberpunk Dashboard (`projects/frontend`)

Este directorio contiene el código fuente del panel de control interactivo de estética cyberpunk para el ecosistema **MechMind-dwv**.

## Características Principales
- **Command Deck:** Supervisión en tiempo real de telemetría y estados del robot.
- **Mech Systems:** Diagnóstico avanzado de actuadores, temperaturas y potencias.
- **Navigation Mesh:** Mapa interactivo con soporte de waypoints (MOVE, SCAN, HOLD) y pasarela ROS2 (rosbridge v2).
- **AI Core:** Visualización del núcleo cognitivo y modelos predictivos.

---

## Puesta en Marcha Local

```bash
cd projects/frontend
pnpm install
pnpm run dev
```
